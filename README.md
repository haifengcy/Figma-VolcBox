## ✨ 核心功能

- 🌐 **AI 智能翻译**：全球 100+ 语言免配置极速翻译；支持 DeepSeek / OpenAI 大模型；完美保留富文本样式与字号颜色。
- 📝 **智能数据填充**：内置中英文常用姓名/城市/价格预设，支持粘贴自定义词库一键批量填充。
- 🖼️ **TinyPNG 极速压缩**：多账号池自动轮询调度（突破单 Key 500 次限制），6 线程并发导出，按钮内嵌实时进度（如 `3/10`）。
- 🎨 **色彩调节**：画板全局 HSL 快速调色，支持本地常用色板归档。
- 🛠️ **效率工具**：画布拼图直出、文本行高批量 Auto / 固定像素互转、PNG 透明边缘自动裁切。
- ☁️ **多端云同步**：专属密钥机制，更换电脑或重装 Figma 粘贴密钥一键恢复所有 API Key 与词库偏好。

## 🚀 快速安装

1. **下载或克隆本仓库**：
   ```bash
   git clone https://github.com/haifengcy/Figma-VolcBox.git
   ```
2. 打开 **Figma**，进入任意设计画板；
3. 点击顶部菜单：`Plugins (插件)` ➔ `Development (开发)` ➔ `Import plugin from manifest...`；
4. 选择本项目中的 **`manifest.json`** 即可直接运行！
