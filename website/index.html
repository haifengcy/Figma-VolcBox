Quick Start

极速 3 步，在 Figma 中开启体验

无需复杂安装配置，开箱即用。

01

下载插件源码包

从 GitHub Releases 下载最新的 `VolcBox_v1.0.0.zip` 压缩包并解压到本地文件夹，或使用 git clone 命令克隆仓库。

02

在 Figma 中导入

打开 Figma 任意文件，点击菜单栏 `Plugins (插件)` ➔ `Development (开发)` ➔ `Import plugin from manifest...`，选中解压出的 `manifest.json`。

03

即刻享受极速提效

选中画板或文字，点击运行 VolcBox Next，开启 AI 智能多语言翻译、批量填充与 TinyPNG 极速压缩！
